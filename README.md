# 🎬 Netflix Case Study — Exploratory Data Analysis

> **Tools Used:** Python | Pandas | NumPy | Matplotlib | Seaborn
> **Dataset:** Netflix Movies & TV Shows

---

## 📌 Objective

To perform exploratory data analysis on the Netflix dataset to uncover content trends, genre patterns, release behavior, and regional distribution.

---

## 🔍 Key Insights

- 📺 **Movies vs TV Shows:** Netflix has significantly more movies than TV shows
- 🌍 **Top Content Country:** USA dominates Netflix content production
- 📅 **Peak Release Year:** Content additions peaked around 2018–2020
- 🎭 **Top Genres:** Drama, Comedy, and Documentary are the most common
- 🔞 **Rating:** TV-MA is the most frequent content rating

---

## 🛠️ Python Libraries Used

- `Pandas` — data loading, cleaning, manipulation
- `NumPy` — numerical operations
- `Matplotlib` — basic visualizations
- `Seaborn` — statistical plots and heatmaps

---

## 📊 Analysis Performed

- Missing value treatment and data cleaning
- Content type distribution (Movies vs TV Shows)
- Year-wise content addition trend
- Top 10 countries by content volume
- Genre frequency analysis
- Rating distribution
- Director and cast analysis
